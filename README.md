# Algorithm Design and Analysis

Well-structured C++ solutions for various algorithm design techniques — includes divide & conquer, greedy, dynamic programming, and more.

## Categories

- **Sorting** — Bubble, Heap, Insertion, Merge, Quick, Selection, Counting, Radix
- **Graph** — Bellman-Ford, Dijkstra, Floyd-Warshall, Graph Coloring, Prim's, TSP, BFS, DFS, Topological Sort, Union-Find, Cycle Detection, Bipartite Check, Kruskal's, Kosaraju SCC
- **DP** — 0/1 Knapsack, Job Sequencing, LCS, LIS, LPS, MCM, Coin Change, Subset Sum, Edit Distance, Rod Cutting, Kadane's Algorithm, Egg Dropping
- **String** — KMP, Rabin-Karp, Trie, Z-Algorithm, Manacher's Algorithm
- **Backtracking** — N-Queen, Sudoku Solver, Permutations, Combinations, Subsets, Rat in a Maze
- **Tree** — BFS, DFS, BST, LCA, Diameter, Level Order
- **Heap** — Min Heap, Max Heap, Kth Largest Element, Median from Stream
- **Searching** — Binary Search
- **Sliding Window** — Sliding Window
- **Two Pointers** — Two Sum, Three Sum
- **Greedy** — Huffman Coding
- **Math** — Magic Square (Odd, Doubly Even, Singly Even)
- **Divide & Conquer** — Strassen's Matrix Multiplication
- **Bit Manipulation** — Basics
